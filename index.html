Урок 01 · 10 минут

Что такое Arduino и зачем оно нужно?

Arduino — это небольшая программируемая плата, с которой можно создавать электронные устройства: от мигающего светодиода до автоматической теплицы. Она считывает сигналы датчиков, выполняет вашу программу и управляет лампами, моторами и другими компонентами.

Простыми словами

Arduino — как маленький мозг конструктора. Датчики — его органы чувств, программа — правила поведения, а светодиоды и моторы — руки, которыми он действует.

Как работает любое устройство на Arduino

1ВходКнопка, датчик света
→
2РешениеПрограмма на плате
→
3ДействиеСвет, звук, движение

Например: если стало темно, то включить ночник. Датчик освещённости сообщает плате уровень света, программа сравнивает его с заданным порогом, а выходной контакт подаёт питание на светодиод.

Что понадобится для старта

▣Arduino Uno

Или совместимая плата. Лучший вариант для обучения.

⌁USB-кабель

Для Uno обычно USB-A → USB-B. Проверьте разъём платы.

⠿Макетная плата

Позволяет собирать схемы без пайки.

◉Детали

Светодиоды, резисторы 220 Ом, кнопки и провода.

Важно про безопасность

Начинайте только с USB-питания 5 В. Не подключайте Arduino к розетке 220 В и не замыкайте контакты 5V и GND проводом. Перед изменением схемы отключайте кабель питания.

Где применяют Arduino?

В учебных роботах, домашней метеостанции, автоматическом поливе, электронных замках, интерактивных инсталляциях и прототипах устройств. Arduino отлично подходит для проверки идеи; готовый промышленный прибор может потребовать другой платы и сертификации.

Урок 02 · 15 минут

Плата и компоненты: разбираем по деталям

Не нужно знать назначение каждого элемента. Для первых проектов достаточно понимать питание, цифровые и аналоговые контакты.

Цифровой сигнал

Имеет два состояния: HIGH (высокий, около 5 В) и LOW (низкий, 0 В). Подходит для ответов «да/нет»: кнопка нажата или нет, светодиод включён или выключен.

Аналоговый сигнал

Может принимать множество значений. На Arduino Uno analogRead() возвращает число от 0 до 1023 — от 0 до 5 В на входе.

Зачем светодиоду резистор?

Светодиод почти не ограничивает ток сам. Без резистора он может перегореть или повредить вывод платы. Для экспериментов с 5 В возьмите резистор 220–330 Ом. Длинная ножка светодиода — анод (+), короткая — катод (−).

Как рассчитать резистор по закону Ома?

Формула: R = (Uпитания − Uсветодиода) / I. Для красного светодиода с падением около 2 В и током 10 мА: (5 − 2) / 0,01 = 300 Ом. Ближайший стандартный номинал — 330 Ом. С резистором 220 Ом ток будет около 13,6 мА. Не превышайте рекомендуемый ток вывода микроконтроллера; для долговечности достаточно 5–15 мА.

Урок 03 · 10 минут

Устанавливаем Arduino IDE и подключаем плату

Arduino IDE — программа, в которой вы пишете скетч, проверяете его и отправляете в плату. «Скетч» — так в мире Arduino называют программу.

  1. 1
    Скачайте Arduino IDE 2

    Откройте официальный сайт arduino.cc/en/software и выберите версию для Windows, macOS или Linux. Не скачивайте установщик со сторонних сайтов.

  2. 2
    Установите и запустите IDE

    Следуйте подсказкам установщика. В Windows система может запросить разрешение на установку драйверов — оно нужно для распознавания плат.

  3. 3
    Подключите плату кабелем

    Используйте именно кабель передачи данных: некоторые USB-кабели предназначены только для зарядки. На плате должен загореться индикатор питания.

  4. 4
    Выберите плату и порт

    В верхнем раскрывающемся списке нажмите «Select Board», затем выберите Arduino Uno и появившийся последовательный порт. Можно также открыть «Инструменты → Плата → Arduino AVR Boards → Arduino Uno».

  5. 5
    Загрузите проверочный пример

    Откройте «Файл → Примеры → 01.Basics → Blink». Нажмите стрелку «Загрузить» в левом верхнем углу. Встроенный светодиод L должен начать мигать.

Урок 04 · 20 минут

Первая программа: мигаем светодиодом

Начнём со встроенного светодиода — для него не нужна схема. Затем разберём каждую строку и подключим внешний светодиод.

Blink.ino
const int LED_PIN = LED_BUILTIN;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_PIN, HIGH);
  delay(1000);
  digitalWrite(LED_PIN, LOW);
  delay(1000);
}

Что означает каждая строка?

const int LED_PIN = LED_BUILTIN;
Задаём понятное имя контакту. LED_BUILTIN автоматически соответствует встроенному светодиоду выбранной платы.
void setup() { ... }
Выполняется один раз после включения или перезапуска. Здесь настраивают контакты и связь.
pinMode(LED_PIN, OUTPUT);
Сообщаем, что контакт будет выходом — плата сможет подавать на него напряжение.
void loop() { ... }
Повторяется бесконечно: сверху вниз, снова и снова, пока плата включена.
digitalWrite(..., HIGH/LOW);
Включает высокий или низкий уровень на выходе.
delay(1000);
Делает паузу 1000 миллисекунд, то есть одну секунду. Во время delay() плата не выполняет другие строки программы.

Подключаем внешний светодиод

Контакт 13 → резистор → анод

Соедините D13 с резистором 220 Ом, а другой вывод резистора — с длинной ножкой светодиода.

Катод → GND

Короткую ножку соедините с любым контактом GND. Цепь должна быть замкнута.

Замените первую строку на const int LED_PIN = 13;. Программа останется прежней, но теперь будет управлять внешним светодиодом.

Практика

Измените ритм мигания

Сделайте сигнал SOS: три коротких включения по 200 мс, три длинных по 600 мс и пауза 1500 мс. Сначала попробуйте сами, затем откройте подсказку.

Показать подсказку

Создайте функцию blink(int duration), которая включает светодиод, ждёт duration, выключает его и делает паузу 200 мс. В loop() вызовите её три раза с 200 и три раза с 600.

Урок 05 · 20 минут

Кнопки и условия: устройство реагирует

Теперь добавим вход. Плата будет проверять состояние кнопки и включать светодиод только при нажатии.

Подключение без внешнего резистора

Соедините один контакт кнопки с D2, а противоположный — с GND. Включим внутренний подтягивающий резистор режимом INPUT_PULLUP. Поэтому логика будет обратной: отпущенная кнопка даёт HIGH, нажатая — LOW.

Почему нельзя оставить вход «в воздухе»?

Не подключённый вход улавливает помехи и случайно меняет состояние. Подтяжка задаёт стабильный уровень, когда кнопка разомкнута. У тактовой кнопки ножки попарно соединены; если она работает непредсказуемо, поверните её на 90°.

Button.ino
const int BUTTON_PIN = 2;
const int LED_PIN = 13;

void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  int buttonState = digitalRead(BUTTON_PIN);

  if (buttonState == LOW) {
    digitalWrite(LED_PIN, HIGH);
  } else {
    digitalWrite(LED_PIN, LOW);
  }
}

Как читать условие

if (buttonState == LOW)→

Если значение равно LOW, выполнить блок в фигурных скобках. Иначе выполнить блок после else. Обратите внимание: == сравнивает значения, а одиночное = присваивает значение.

Полезные операторы

== равно, != не равно, > больше, < меньше, && и, || или, ! не.

Дребезг контактов

Реальная кнопка при нажатии может несколько раз замыкаться и размыкаться. Для переключателей добавляют антидребезг: проверяют, что состояние стабильно хотя бы 20–50 мс.

Попробуйте сами

Сделайте переключатель

Измените программу так, чтобы каждое нажатие меняло состояние светодиода, а не удерживало его. Сохраняйте состояние в переменной bool ledOn = false; и реагируйте на момент нажатия, а не на удержание.

Урок 06 · 25 минут

Аналоговый мир: датчики и плавный свет

Освещённость, температура и положение ручки редко бывают только «включено» и «выключено». Аналоговый вход позволяет измерять такие величины.

Потенциометр как регулятор

Подключите крайние выводы потенциометра к 5V и GND, средний — к A0. Вращение ручки меняет напряжение на среднем выводе. Светодиод с резистором подключите к контакту 9 и GND.

AnalogControl.ino
const int KNOB_PIN = A0;
const int LED_PIN = 9;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  int sensorValue = analogRead(KNOB_PIN);
  int brightness = map(sensorValue, 0, 1023, 0, 255);
  analogWrite(LED_PIN, brightness);
}
0 … 1023analogRead()10-битный вход Uno
map()
0 … 255analogWrite()8-битное значение ШИМ

map() пропорционально переводит число из одного диапазона в другой. analogWrite() на Uno создаёт ШИМ — быстро переключает выход между HIGH и LOW. Чем больше доля времени во включённом состоянии, тем ярче кажется светодиод.

Аналоговый вход ≠ аналоговый выход

analogWrite() на Arduino Uno не выдаёт плавно меняющееся постоянное напряжение, а формирует ШИМ. Для управления яркостью это отлично работает. Для настоящего аналогового напряжения нужен ЦАП или фильтр.

Как подключить фоторезистор?

Соберите делитель напряжения: один вывод фоторезистора к 5V, второй к A0; между A0 и GND поставьте постоянный резистор около 10 кОм. Чем темнее, тем обычно выше сопротивление фоторезистора. Считайте A0 и посмотрите значения в Мониторе порта. Направление изменения зависит от того, каким элементом делитель подключён к 5V.

Монитор порта: разговор с платой

Монитор порта показывает сообщения от Arduino прямо в IDE. Это главный помощник для отладки: вы видите значения датчиков и понимаете, какую часть кода выполняет плата.

SerialMonitor.ino
void setup() {
  Serial.begin(9600);
  Serial.println("Arduino готова!");
}

void loop() {
  int value = analogRead(A0);
  Serial.print("Значение A0: ");
  Serial.println(value);
  delay(500);
}
  1. Загрузите скетч и нажмите значок лупы справа вверху.
  2. Внизу Монитора порта выберите скорость 9600 бод — такую же, как в Serial.begin(9600).
  3. Поворачивайте потенциометр: числа должны меняться от 0 до 1023.

print() или println()?

print() выводит текст и остаётся на той же строке. println() после вывода добавляет переход на новую строку.

Если видите странные символы

Чаще всего скорость в Мониторе порта не совпадает со скоростью в скетче. Установите одинаковое значение в обоих местах.

Полезный приём отладки

Добавьте Serial.println("Проверка 1"); после участка кода. Если сообщение появилось, плата дошла до этой строки. Выводите не только текст, но и промежуточные значения переменных.

NightLight.ino
const int LIGHT_SENSOR = A0;
const int LED_PIN = 9;
const int THRESHOLD = 400;

void setup() {
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int lightLevel = analogRead(LIGHT_SENSOR);
  Serial.println(lightLevel);

  if (lightLevel < THRESHOLD) {
    analogWrite(LED_PIN, 180);
  } else {
    analogWrite(LED_PIN, 0);
  }
  delay(100);
}
Настройте порог именно под вашу схему

Значение 400 — только отправная точка. Откройте Монитор порта, посмотрите показания при дневном свете и в желаемой темноте, затем выберите порог между ними. Если при затемнении значение растёт, замените < на >.

Улучшите проект

Сделайте плавное включение

Вместо резкой смены яркости используйте цикл for (int brightness = 0; brightness <= 180; brightness++), внутри вызывайте analogWrite() и delay(10). Добавьте небольшой гистерезис: отдельные пороги включения и выключения, чтобы свет не дрожал на границе.

Цифровой вход · антидребезг

Кнопка-переключатель

Сделаем так, чтобы короткое нажатие меняло состояние светодиода, а удержание кнопки не вызывало непрерывное переключение.

Соберите схему

D2 → кнопка → GND; D13 → резистор 220 Ом → анод светодиода; катод → GND. Для кнопки используем внутреннюю подтяжку INPUT_PULLUP.

DebouncedToggle.ino
const int BUTTON_PIN = 2;
const int LED_PIN = 13;
bool ledOn = false;
bool lastReading = HIGH;
bool stableState = HIGH;
unsigned long lastChange = 0;

void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  bool reading = digitalRead(BUTTON_PIN);
  if (reading != lastReading) {
    lastChange = millis();
    lastReading = reading;
  }
  if (millis() - lastChange >= 30 && reading != stableState) {
    stableState = reading;
    if (stableState == LOW) {
      ledOn = !ledOn;
      digitalWrite(LED_PIN, ledOn);
    }
  }
}

Как это работает

При любом изменении входа программа запускает отсчёт заново. Новое состояние признаётся настоящим только после 30 мс стабильности. Переключение происходит один раз — в момент подтверждённого нажатия LOW. Вычитание millis() - lastChange корректно работает и при переполнении таймера.

Таймеры · без delay()

Два независимых процесса

Один светодиод будет мигать каждые 300 мс, другой — каждые 1000 мс. Оба процесса выполняются в одном loop() и не блокируют друг друга.

Соберите схему

Первый светодиод через резистор 220 Ом подключите к D12, второй через отдельный резистор — к D13. Катоды соедините с GND.

TwoTimers.ino
unsigned long fastPrevious = 0;
unsigned long slowPrevious = 0;
bool fastState = false;
bool slowState = false;

void setup() {
  pinMode(12, OUTPUT);
  pinMode(13, OUTPUT);
}

void loop() {
  unsigned long now = millis();
  if (now - fastPrevious >= 300) {
    fastPrevious = now;
    fastState = !fastState;
    digitalWrite(12, fastState);
  }
  if (now - slowPrevious >= 1000) {
    slowPrevious = now;
    slowState = !slowState;
    digitalWrite(13, slowState);
  }
}

Почему здесь нет delay()

millis() возвращает время работы платы в миллисекундах. Программа мгновенно проверяет оба таймера и идёт дальше. Поэтому сюда легко добавить опрос кнопки или датчика. Сохранение previous = now задаёт период от момента срабатывания; для более строгого расписания используют previous += interval.

RGB-светодиод и смешивание цветов

Красный, зелёный и синий каналы управляются независимо. Меняя яркость каждого от 0 до 255, можно получить множество оттенков.

Соберите схему

Для RGB-светодиода с общим катодом: каналы R, G, B через отдельные резисторы 220 Ом подключите к D9, D10, D11, общий катод — к GND. У модели с общим анодом схема и логика будут другими.

RGBColor.ino
const int RED_PIN = 9;
const int GREEN_PIN = 10;
const int BLUE_PIN = 11;

void setColor(int red, int green, int blue) {
  analogWrite(RED_PIN, red);
  analogWrite(GREEN_PIN, green);
  analogWrite(BLUE_PIN, blue);
}

void setup() {
  pinMode(RED_PIN, OUTPUT);
  pinMode(GREEN_PIN, OUTPUT);
  pinMode(BLUE_PIN, OUTPUT);
}

void loop() {
  setColor(255, 80, 0);
  delay(1000);
  setColor(0, 180, 255);
  delay(1000);
}

Функция убирает повторения

setColor() принимает три значения и управляет всеми каналами сразу. Теперь для смены оттенка достаточно одной строки. Значения можно получать с трёх потенциометров или плавно изменять в цикле.

Ультразвук · измерение времени

Парковочный помощник на HC-SR04

Датчик отправляет короткий ультразвуковой импульс и измеряет время возвращения эха. Чем ближе препятствие, тем чаще звучит сигнал и тем тревожнее индикация.

Соберите схему

VCC → 5V, GND → GND, TRIG → D7, ECHO → D8. Красный, жёлтый и зелёный светодиоды через отдельные резисторы подключите к D4, D3 и D2. Для звука можно добавить пьезодинамик на D9.

DistanceMeter.ino
const int TRIG_PIN = 7;
const int ECHO_PIN = 8;

void setup() {
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
  Serial.begin(9600);
}

void loop() {
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);

  unsigned long duration = pulseIn(ECHO_PIN, HIGH, 30000);
  if (duration == 0) {
    Serial.println("Эхо не получено");
  } else {
    float distance = duration * 0.0343 / 2;
    Serial.print(distance);
    Serial.println(" см");
  }
  delay(100);
}

Почему делим на два

Звук проходит путь до препятствия и обратно. Скорость звука около 343 м/с, поэтому расстояние в сантиметрах приблизительно равно время_мкс × 0,0343 / 2. Тайм-аут 30 000 мкс не даёт pulseIn() ждать слишком долго. Для индикации добавьте условия: до 20 см — красный, 20–50 см — жёлтый, дальше — зелёный.

Игра на реакцию

После старта светодиод загорается через случайный интервал. Игрок должен нажать кнопку как можно быстрее — но нажатие раньше сигнала засчитывается как фальстарт.

Соберите схему

Кнопку подключите между D2 и GND, светодиод через резистор 220 Ом — к D13. Кнопка работает в режиме INPUT_PULLUP.

ReactionGame.ino
enum State { IDLE, WAITING, SIGNAL };
State state = IDLE;
const int BUTTON_PIN = 2;
const int LED_PIN = 13;
unsigned long signalAt = 0;
unsigned long signalTime = 0;
bool previousButton = HIGH;

bool buttonPressed() {
  bool current = digitalRead(BUTTON_PIN);
  bool pressed = previousButton == HIGH && current == LOW;
  previousButton = current;
  return pressed;
}

void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
  randomSeed(analogRead(A0));
  Serial.println("Нажмите кнопку для старта");
}

void loop() {
  bool pressed = buttonPressed();
  switch (state) {
    case IDLE:
      if (pressed) {
        digitalWrite(LED_PIN, LOW);
        signalAt = millis() + random(1000, 4001);
        state = WAITING;
        Serial.println("Ждите сигнал…");
      }
      break;
    case WAITING:
      if (pressed) {
        Serial.println("Фальстарт!");
        state = IDLE;
      } else if ((long)(millis() - signalAt) >= 0) {
        digitalWrite(LED_PIN, HIGH);
        signalTime = millis();
        state = SIGNAL;
        Serial.println("Нажимайте!");
      }
      break;
    case SIGNAL:
      if (pressed) {
        Serial.print("Реакция: ");
        Serial.print(millis() - signalTime);
        Serial.println(" мс");
        digitalWrite(LED_PIN, LOW);
        state = IDLE;
      }
      break;
  }
}

Программа помнит своё состояние

В IDLE игра ждёт старт, в WAITING проверяет фальстарт и случайный таймер, в SIGNAL измеряет реакцию. Функция buttonPressed() замечает только переход от отпущенной кнопки к нажатой. Для реального устройства добавьте антидребезг из первого примера, чтобы вибрация контактов не создавала ложных нажатий.

Частые вопросы

Остались сомнения перед стартом? Скорее всего, ответ уже здесь.

Нужно ли уметь программировать?+

Нет. Курс начинается с самых основ. Сначала вы будете менять готовые примеры, затем постепенно научитесь писать собственные программы. Достаточно базовых навыков работы с компьютером.

Какую плату купить первой?+

Для этого курса удобнее всего Arduino Uno или качественная совместимая плата с тем же расположением контактов. Проверьте тип USB-разъёма и наличие кабеля в комплекте. Набор с макетной платой, резисторами, светодиодами и проводами избавит от отдельных покупок.

Можно ли учиться совсем без платы?+

Да: читайте уроки и экспериментируйте с нашим браузерным симулятором. Для полноценной практики также существуют внешние электронные симуляторы, но реальная плата даёт важный опыт сборки и поиска неисправностей.

Чем Arduino отличается от Raspberry Pi?+

Arduino Uno — плата с микроконтроллером для простых задач в реальном времени: опросить датчик, включить мотор. Raspberry Pi — одноплатный компьютер с операционной системой. Для сложных вычислений, камеры и веб-сервера чаще выбирают Raspberry Pi, для простого управления электроникой — микроконтроллер.

Можно ли питать мотор прямо от контакта Arduino?+

Нет. Вывод микроконтроллера не рассчитан на ток мотора. Используйте подходящий драйвер, отдельное питание нужной мощности и общий GND. Для индуктивной нагрузки нужна защита от выбросов напряжения; схема зависит от драйвера и мотора.

Что изучать после этого курса?+

Освойте функции, массивы, библиотеки, неблокирующие задержки на millis(), прерывания и протоколы I²C/SPI. Затем выберите собственный проект: он поможет собрать знания в систему лучше, чем бесконечное чтение теории.
